# HandGestureBot
Hand Gesture Controlled Robot

Designed and developed a hand gesture-controlled robotic system using sensor-based automation and embedded system concepts.

Project Overview

The robot responds to hand gestures and performs directional movements based on input signals from gesture detection mechanisms.

Features

- Gesture-based robotic control
- Wireless movement operation
- Embedded hardware integration
- Automation and control system concepts

Tools & Technologies

- Embedded Systems
- Arduino / Microcontroller Concepts
- Sensors and Automation
- Proteus Simulation

Achievements

- Secured 2nd Prize for project innovation and implementation during college project evaluation.

Learning Outcomes

- Practical exposure to robotics and automation
- Hardware-software interfacing
- Sensor integration and control systems

Status

Academic project completed during undergraduate coursework.
